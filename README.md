# 🛡️ CyberTwin AI

> “Predictive AI-Powered Cybersecurity Digital Twin Platform”

CyberTwin AI is an intelligent cybersecurity simulation dashboard that creates a virtual security twin of a user’s digital presence. It predicts cyber risks, visualizes attack propagation, detects phishing/spam threats, and helps users improve their online security posture using AI and machine learning.

---

# 🚨 Problem Statement

In today’s digital world, users operate across multiple online platforms such as email, social media, and professional networks. However, most users:

- Reuse passwords across accounts
- Ignore Two-Factor Authentication (2FA)
- Fall victim to phishing attacks
- Lack awareness of cyber risks
- Cannot visualize how attacks spread across platforms

Traditional cybersecurity tools are often reactive and only detect threats after compromise occurs.

CyberTwin AI addresses this gap by providing predictive cybersecurity intelligence and interactive attack simulations.

---

# 💡 Solution

CyberTwin AI creates a simulated digital twin of a user’s online presence and analyzes multiple security factors including:

- Password reuse
- 2FA usage
- Exposure levels
- Phishing susceptibility
- Platform vulnerabilities

Using multiple machine learning models, the system predicts cyber risk levels and visualizes potential attack chains before an actual compromise occurs.

The platform also includes:
- Real-time spam/phishing analysis
- Password strength evaluation
- AI-powered recommendations
- Interactive attack graphs

---

# ✨ Features

## 🧠 AI Risk Prediction
Uses multiple machine learning algorithms to calculate cyber risk scores:
- Logistic Regression
- Random Forest
- Decision Tree
- Gradient Boosting
- SVM
- KNN

---

## 📩 Spam & Phishing Detection
Fetches real emails and analyzes suspicious/spam patterns using keyword-based threat detection.

---

## ⚠️ Attack Simulation
Simulates real-world cyber attack scenarios such as:
- Phishing attacks
- Credential theft
- Account takeover
- Malware propagation

---

## 🔑 Password Strength Checker
Analyzes password strength based on:
- Length
- Uppercase characters
- Numbers
- Special symbols

---

## 🕸️ Attack Graph Visualization
Visualizes how cyber attacks propagate across interconnected accounts and platforms.
